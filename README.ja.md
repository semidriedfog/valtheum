# valtheum

[한국어](README.md) · [English](README.en.md) · **日本語**

**フォルダー内の動画・写真・画像アーカイブ・PDF・暗号化メモをまとめて管理する Windows アプリです。**

Rust と WebView2 で動作します。アカウントや外部サーバーを使わずにローカルのライブラリを利用できます。英語を既定言語とし、韓国語・日本語にも対応しています。

**パスワードの設定と暗号化は任意です。** 暗号化せずに動画・画像・画像アーカイブ・PDF を閲覧し、一覧・タグ・評価・シリーズを管理できます。メディアの暗号化や暗号化メモを利用する場合にのみ、DB の暗号化とパスワードの設定が必要です。

[使い始める](#使い始める) · [対応形式](#対応形式) · [暗号化とバックアップ](#暗号化とバックアップ) · [ビルド手順（韓国語）](docs/BUILD.md) · [セキュリティと復元（韓国語）](docs/SECURITY.md)

## 主な機能

- **メディアの閲覧** — 動画再生、アーカイブ内画像の数字順表示、個別画像の閲覧、PDF の2ページ表示と前回のページからの再開。
- **ライブラリの整理** — 仮想スクロールによる一覧、ファイル名・シリーズの検索、独立したタグ検索、評価・スコア・日付による並べ替え、ごみ箱と削除履歴。
- **シリーズとアリーナ** — 複数のファイルを1つのシリーズとして並べ替え、タグ・評価・スコアを共有します。アリーナではシリーズの代表ファイルだけを比較します。
- **任意の暗号化** — SQLCipher による DB 暗号化、画像アーカイブ・動画・個別画像の暗号化、独立した暗号化メモ。保護したいライブラリフォルダーにだけパスワードを設定できます。
- **復元ツール** — DB・鍵のバックアップと新しいフォルダーへの復元、独立したメディア復元 GUI・CLI、簡易整合性チェック、NAS への再接続。
- **写真ギャラリー** — 起動画面用に別の写真フォルダーを指定できます。表示間隔を調整できる全画面のフォトフレームモードも利用できます。

## 使い始める

Windows と **Microsoft Edge WebView2 Runtime** が必要です。ソースコードのみを入手した場合は、先に[実行ファイルをビルド](#ソースからビルドする)してください。ソースリポジトリに実行ファイルは含まれていません。

| 実行ファイル | 用途 |
| --- | --- |
| `valtheum.exe` | メディアライブラリアプリ |
| `valtheum-restore.exe` | アプリの DB を使わずに暗号化メディアを復元する GUI |
| `valtheum-restore-cli.exe` | コマンドライン復元ツール。WebView2 は不要 |

1. `valtheum.exe` を起動します。最初に写真ギャラリーが表示されます。
2. **写真ライブラリ / Photo library** ラベルを **2.5秒以内に5回クリック**します。
3. 管理する実際のライブラリフォルダーを選択します。DB が暗号化されている場合は、そのフォルダーのパスワードを入力します。
4. フォルダーを同期し、一覧からメディアを選択します。

実際のライブラリフォルダーの一覧は、アプリの実行中のみ保持します。再起動後はフォルダーを再指定してください。公開ギャラリーのフォルダー・フォトフレームの表示間隔・言語は `vault_config.json` に保存します。既定の写真は同梱していません。

## 対応形式

| 種類 | 対応範囲 |
| --- | --- |
| 動画 | MP4、MKV、WebM、AVI、MOV、M4V。再生の可否は WebView2 のコーデック対応状況によります。 |
| 個別画像 | JPG、JPEG、PNG、WebP、GIF、BMP、AVIF |
| 画像アーカイブ | ZIP・TAR.ZST 内の画像 |
| PDF | ページ全体・幅に合わせる表示、拡大、2ページ表示、ホイール操作、ページ移動スライダー、前回のページからの再開、パスワード入力 |
| 暗号化ファイル | 画像アーカイブ `.vta`、動画 `.vtv`、画像 `.vti`、独立メモ `.vtn` |

RAR・7z は一覧への登録のみ対応し、開くことはできません。単独の `.zst` と `.cbz` も非対応です。TAR.ZST は先頭から順に展開するため、後半のページは読み込みに時間がかかる場合があります。アーカイブの上限は、画像1枚あたり展開後 32 MiB、項目数 100,000 件です。

PDF.js とフォントを同梱し、PDF をオフラインで表示します。PDF のスクリプト・外部リンク・フォーム編集・テキスト検索・PDF ファイル自体の暗号化には対応していません。

## 使い方のヒント

- 閲覧中のメディアは一覧で **オレンジ色**、シリーズは **金色の枠**で表示します。
- アリーナの選択キーは **V / B** です。シリーズは代表ファイルのみが比較対象になります。
- 動画上でマウスホイールを動かすと再生位置を移動できます。画像アーカイブ・PDF ではページを切り替えます。
- 保存したページ・再生位置はメディア上に重ねて表示され、閲覧領域を狭めません。一覧を読み込めない場合は、保存位置の一覧を再読み込みして確認できます。
- シリーズの保存は画面を閉じても続行されます。再度開くと進行状況を確認でき、結果が不明な場合は **保存結果を確認** を押します。結果を確認するまで、新しい保存・シリーズ解除は開始できません。
- 動画は実際に10秒間再生した後、画像アーカイブ・PDF は異なる5ページを閲覧した後に閲覧回数を記録します。
- **＋ 新しいメモ**では、写真を使わずに独立したメモを作成できます。タイトル検索・タグ・評価・ごみ箱に対応し、アリーナとシリーズの対象からは除外されます。
- 暗号化した画像アーカイブでは、表示名・復元時のファイル名を変更したり、複数の画像を選択して削除したりできます。編集前のバックアップを推奨します。

## 暗号化とバックアップ

| 利用方法 | パスワードと暗号化 |
| --- | --- |
| 通常のメディア閲覧・管理 | ライブラリのパスワードは不要です。DB とメディアは暗号化せずに使用します。 |
| DB のみ暗号化 | 任意です。フォルダーのパスワードでタグなどの DB 情報を保護し、既存のメディアファイルは変更しません。 |
| メディアの暗号化・暗号化メモ | 先に暗号化された DB のロックを解除する必要があります。メモは常に暗号化して保存します。 |

PDF 自体にパスワードが設定されている場合は、ライブラリの設定とは別に、その PDF のパスワードが必要です。

**DB の暗号化とメディアの暗号化は別の操作です。** DB には一覧・タグ・評価・サムネイルなどを保存し、メディア本体はファイルとして保管します。メディアの暗号化やメモの保存には、先に DB を暗号化してロックを解除する必要があります。

| 保管するもの | 内容 |
| --- | --- |
| アプリで作成した `.vtbackup` | 現在のフォルダーの DB と、作成済みの場合は `.valtheum/vault.key` |
| `.valtheum/archives`、`videos`、`images`、`notes` | 別途バックアップが必要な暗号化メディア本体 |
| 平文メディア | 暗号化していない原本。必要に応じて別途バックアップ |

**DB のバックアップだけでは、メディアやメモの本文を復元できません。** DB・鍵とメディアを一緒に保管し、メディアの編集後は両方のバックアップを更新してください。メディアを単独で復元するには、暗号化ファイル・対応する `vault.key`・鍵のパスワードが必要です。

暗号化では新しいコピーを作成して検証し、**平文の原本は自動削除しません。** バックアップと閲覧を確認してから原本の削除機能を使用してください。パスワードはアプリ内で変更すると、DB と鍵の両方に適用されます。

簡易整合性チェックでは、ファイルの存在・サイズ、DB と鍵の一致、暗号化メタデータと境界部分のブロックを確認します。**全データの検査や破損の修復を行う機能ではありません。** 起動時のギャラリーも、エクスプローラー内のファイルや OS の記録を隠すものではありません。

詳しい手順と保護範囲は[セキュリティ・バックアップ・復元ガイド（韓国語）](docs/SECURITY.md)、ファイル形式は[暗号化フォーマット仕様（英語）](docs/VTA_FORMAT.md)を参照してください。

## ソースからビルドする

Windows MSVC 用 Rust ツールチェーン、Visual Studio C++ Build Tools と Windows SDK、OpenSSL ビルド用の Perl を用意します。フロントエンドのテストには Node.js が必要です。

プロジェクトのルートで PowerShell を開き、次を実行します。

```powershell
cargo fetch --locked
.\scripts\build.ps1
```

実行ファイルは `target/release/` に生成されます。画面のコードは実行ファイルに埋め込まれるため、UI を変更した場合も再ビルドが必要です。初回の環境構築、既存の OpenSSL の利用、テスト・配布手順は[開発・ビルドガイド（韓国語）](docs/BUILD.md)にまとめています。
