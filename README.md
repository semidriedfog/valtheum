# valtheum

**한국어** · [English](README.en.md) · [日本語](README.ja.md)

**폴더에 보관한 영상·사진·이미지 압축 파일·PDF와 암호화 메모를 한곳에서 관리하는 Windows 앱입니다.**

Rust와 WebView2로 동작합니다. 계정이나 외부 서버 없이 로컬 라이브러리를 사용하며, 영어를 기본으로 한국어·일본어를 지원합니다.

**비밀번호 설정과 암호화는 선택사항입니다.** 암호화하지 않고도 영상·이미지·이미지 압축 파일·PDF를 열람하고 목록·태그·별점·시리즈를 관리할 수 있습니다. 미디어 암호화나 암호화 메모를 사용할 때에는 DB 암호화와 비밀번호 설정이 필요합니다.

[시작하기](#시작하기) · [지원 형식](#지원-형식) · [암호화와 백업](#암호화와-백업) · [빌드 안내](docs/BUILD.md) · [보안·복원 안내](docs/SECURITY.md)

## 주요 기능

- **미디어 열람** — 영상 재생, 압축 내부 이미지의 숫자순 탐색, 개별 이미지 보기, PDF 두 페이지 보기와 마지막 페이지 이어보기.
- **라이브러리 정리** — 가상 스크롤 목록, 파일명·시리즈 검색과 별도 태그 검색, 별점·점수·날짜 정렬, 휴지통과 삭제 이력.
- **시리즈와 아레나** — 여러 파일을 하나의 시리즈로 정렬하고 태그·별점·점수를 공유합니다. 아레나에서는 대표 파일끼리 비교합니다.
- **선택적 암호화** — SQLCipher DB, 이미지 압축·영상·이미지의 개별 암호화, 독립적인 암호화 메모. 필요한 라이브러리 폴더에만 비밀번호를 설정할 수 있습니다.
- **복구 도구** — DB·키 백업과 새 폴더 복원, 독립 미디어 복원 GUI·CLI, 빠른 무결성 검사와 NAS 재연결.
- **사진 갤러리** — 시작 화면에 별도 사진 폴더를 지정하고, 표시 시간을 조절하는 전체 화면 액자 모드로 사용할 수 있습니다.

## 시작하기

Windows와 **Microsoft Edge WebView2 Runtime**이 필요합니다. 소스만 받았다면 먼저 [빌드 안내](docs/BUILD.md)를 따라 실행 파일을 만드세요. 실행 파일은 소스 저장소에 포함하지 않습니다.

| 실행 파일 | 용도 |
| --- | --- |
| `valtheum.exe` | 미디어 라이브러리 앱 |
| `valtheum-restore.exe` | 앱 DB 없이 암호화 미디어를 복원하는 GUI |
| `valtheum-restore-cli.exe` | 명령줄 복원 도구. WebView2 불필요 |

1. `valtheum.exe`를 실행합니다. 처음에는 사진 갤러리가 표시됩니다.
2. **Photo Library / 사진 라이브러리** 라벨을 **2.5초 안에 5번 클릭**합니다.
3. 관리할 실제 폴더를 지정합니다. 암호화된 DB가 있다면 해당 폴더의 비밀번호를 입력합니다.
4. 폴더를 동기화한 뒤 목록에서 미디어를 선택합니다.

실제 라이브러리 폴더 목록은 실행 중에만 유지합니다. 앱을 다시 실행하면 폴더를 다시 지정합니다. 공개 갤러리 폴더·액자 표시 시간·언어는 `vault_config.json`에 저장합니다. 기본 사진은 내장하지 않습니다.

## 지원 형식

| 종류 | 지원 범위 |
| --- | --- |
| 영상 | MP4, MKV, WebM, AVI, MOV, M4V. 실제 재생은 WebView2의 코덱 지원에 따릅니다. |
| 개별 이미지 | JPG, JPEG, PNG, WebP, GIF, BMP, AVIF |
| 이미지 압축 | ZIP, TAR.ZST 내부 이미지 |
| PDF | 페이지·너비 맞춤, 확대, 두 페이지 보기, 휠 이동, 페이지 진도바, 마지막 페이지 복원, 비밀번호 입력 |
| 암호화 파일 | 이미지 압축 `.vta`, 영상 `.vtv`, 이미지 `.vti`, 독립 메모 `.vtn` |

RAR·7z는 목록 등록만 가능하고 열기는 지원하지 않습니다. 단독 `.zst`와 `.cbz`도 지원하지 않습니다. TAR.ZST는 순차 압축 해제로 인해 뒤쪽 페이지가 느릴 수 있습니다. 압축 내부 이미지 한 장은 해제 후 32 MiB, 항목 수는 100,000개까지 허용합니다.

PDF.js와 글꼴을 포함해 PDF를 오프라인으로 표시합니다. PDF 스크립트·외부 링크·양식 편집·텍스트 검색·PDF 파일 자체 암호화는 지원하지 않습니다.

## 사용 팁

- 현재 보고 있는 미디어는 목록에서 **주황색**, 시리즈는 **금색 테두리**로 표시합니다.
- 아레나 선택 단축키는 **V / B**입니다. 시리즈에서는 대표 파일만 비교에 참여합니다.
- 영상 위에서 마우스 휠로 재생 위치를 이동할 수 있습니다. 이미지 압축·PDF는 휠로 페이지를 넘깁니다.
- 저장한 페이지·재생 위치는 미디어 위에 겹쳐 표시되어 열람 영역을 줄이지 않습니다. 저장 목록을 읽지 못하면 **저장 목록 다시 불러오기**로 재확인합니다.
- 시리즈 저장 중 창을 닫아도 작업은 계속됩니다. 다시 열면 진행 상태를 확인할 수 있으며, 결과가 불확실하면 **저장 결과 확인**을 누릅니다. 결과가 확인되기 전에는 새 저장·해제를 시작하지 않습니다.
- 영상은 실제 재생 10초, 이미지 압축·PDF는 서로 다른 5페이지를 본 뒤 열람 횟수를 기록합니다.
- **＋ 새 메모**는 사진 없이 독립 메모를 만듭니다. 메모는 제목 검색·태그·별점·휴지통을 지원하며, 아레나와 시리즈에서는 제외됩니다.
- 암호화된 이미지 압축 파일은 표시 이름·복원 파일명을 바꾸거나 내부 이미지를 여러 장 선택해 삭제할 수 있습니다. 편집 전 백업을 권장합니다.

## 암호화와 백업

| 사용 방식 | 비밀번호와 암호화 |
| --- | --- |
| 일반 미디어 열람·관리 | 라이브러리 비밀번호 불필요. DB와 미디어는 암호화하지 않은 상태로 사용합니다. |
| DB만 암호화 | 선택사항. 폴더 비밀번호로 목록·태그 등 DB 정보를 보호하며, 기존 미디어 파일은 그대로입니다. |
| 미디어 암호화·암호화 메모 | 암호화된 DB를 먼저 잠금 해제해야 합니다. 메모는 항상 암호화해 저장합니다. |

파일 자체에 비밀번호가 걸린 PDF는 라이브러리 설정과 별개로 해당 PDF의 비밀번호가 필요합니다.

**DB 암호화와 미디어 암호화는 별도 작업입니다.** DB에는 목록·태그·별점·썸네일 등이 저장되며, 미디어 본문은 파일로 보관합니다. 미디어 암호화와 메모 저장에는 먼저 DB 암호화와 잠금 해제가 필요합니다.

| 보관할 항목 | 포함하는 내용 |
| --- | --- |
| 앱에서 만든 `.vtbackup` | 현재 폴더의 DB와, 생성되어 있다면 `.valtheum/vault.key` |
| `.valtheum/archives`, `videos`, `images`, `notes` | 별도로 백업해야 하는 암호화 미디어 본문 |
| 평문 미디어 | 암호화하지 않은 원본. 필요에 따라 별도 백업 |

**DB 백업만으로 미디어나 메모 본문을 복원할 수 없습니다.** DB·키와 미디어를 함께 보관하고, 미디어 편집 후에는 두 백업을 함께 갱신하세요. 미디어 독립 복원에는 암호화 파일·해당 `vault.key`·키 비밀번호가 필요합니다.

암호화는 검증된 새 사본을 생성하고 **평문 원본을 자동 삭제하지 않습니다.** 백업과 열람을 확인한 뒤 원본 정리 기능을 사용하세요. 비밀번호 변경은 앱에서 수행해야 DB와 키에 함께 적용됩니다.

빠른 무결성 검사는 파일 존재·크기, DB·키 일치와 암호화 파일의 메타데이터·경계 블록을 확인합니다. **전체 본문 검사나 손상 복구 기능은 아닙니다.** 시작 갤러리 역시 탐색기의 파일이나 OS 기록을 숨기는 보안 기능은 아닙니다.

자세한 절차와 보호 범위는 [보안·백업·복원 안내](docs/SECURITY.md), 형식은 [암호화 포맷 명세](docs/VTA_FORMAT.md)를 참고하세요.

## 소스에서 빌드하기

Windows MSVC Rust 도구 체인, Visual Studio C++ Build Tools·Windows SDK, OpenSSL 빌드용 Perl을 준비합니다. 프런트엔드 테스트에는 Node.js가 필요합니다.

프로젝트 루트의 PowerShell에서:

```powershell
cargo fetch --locked
.\scripts\build.ps1
```

결과는 `target/release/`에 생성됩니다. 앱 화면은 실행 파일에 포함되므로 화면 코드를 바꾼 뒤에도 재빌드해야 합니다. 최초 환경 설정, 기존 OpenSSL 사용, 테스트·배포 절차는 [개발 및 빌드 안내](docs/BUILD.md)에 모았습니다.
