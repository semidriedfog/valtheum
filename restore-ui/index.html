03암호화된 미디어 파일

.valtheum의 .vta · .vtv · .vti · .vtn 파일 · 여러 개 선택 가능

    비밀번호는 저장하지 않습니다. 복원된 미디어와 내보낸 메모 JSON은 암호화되지 않은 파일입니다.

    파일과 폴더를 선택한 뒤 비밀번호를 입력하세요.
    암호화 파일과 키 백업은 그대로 보존됩니다.
      복원 방법과 자주 묻는 질문
      • vtbackup만 있으면 되나요? DB·키 백업에는 미디어가 없습니다. 별도 보관한 .valtheum/archives/*.vta 또는 .valtheum/videos/*.vtv, .valtheum/images/*.vti, .valtheum/notes/*.vtn도 필요합니다. 키를 포함하지 않은 오래된 백업은 사용할 수 없습니다.
      • 이 도구는 무엇을 복원하나요? 영상과 이미지 압축 파일의 원본 바이트를 복원합니다. 태그·별점·시리즈 등 DB 정보는 valtheum에서 DB 백업을 복원해야 합니다.
      • 파일 이름과 폴더는 어떻게 되나요? 원래 파일명으로 선택한 폴더에 저장합니다. 하위 폴더는 재생성하지 않습니다. 같은 이름의 파일은 덮어쓰지 않고 실패로 표시하므로 다른 폴더에 복원하세요.
      • 검증이나 복원에 실패하면요? 비밀번호와 라이브러리의 키가 맞는지 확인하세요. 손상된 파일은 성공으로 처리하지 않습니다. 실패한 항목과 이유를 표시하고 다음 파일을 계속합니다.
      • 취소하면 어떻게 되나요? 완료된 파일은 유지하고 진행 중인 임시 파일은 정리합니다. 원본 암호문은 삭제하지 않습니다. 복원 중 창을 닫아도 정리 후 종료합니다.
      • 키나 비밀번호를 잃었다면요? 해당 키 파일과 비밀번호가 모두 있어야 합니다. 이 도구에는 분실한 키·비밀번호를 대신하는 기능이 없습니다.

      독립 메모(.vtn)는 일반 복원으로 제목과 본문이 담긴 평문 JSON을 만듭니다.

      전체 구간 인증 · 원본 SHA-256 검증 후 저장 · 외부 서버 연결 없음
