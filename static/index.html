#

빠른 무결성 검사

DB와 키를 확인하고, 암호화 파일의 처음·끝 일부 블록만 읽습니다. 일반 파일은 존재 여부와 크기를 확인합니다.

파일 전체 해시·중간 데이터·이미지 디코딩은 검사하지 않습니다. 빠른 검사 통과가 파일 전체의 정상 상태를 보장하지는 않습니다.

파일을 변경하거나 복원하지 않습니다. NAS 연결 문제는 손상과 구분하여 표시합니다.

    상세 결과는 처음 1,000개까지만 표시합니다. 위 집계에는 모든 결과가 포함됩니다.

    창을 닫아도 검사는 계속됩니다. 취소해도 이미 진행 중인 운영체제의 저장소 요청은 즉시 중단되지 않을 수 있습니다.

    DB 백업 복원

    .vtbackup 파일의 DB와 vault.key를 함께 복원합니다. 저장할 상위 폴더를 고르면 그 안에 새 라이브러리 폴더를 만들고 엽니다.

    선택한 파일 없음

    미디어 파일은 백업에 포함되지 않습니다. 복원된 폴더에 원래 경로대로 미디어를 복사한 뒤 동기화해 주세요. 미디어가 아직 없어도 기존 기록은 보존합니다.
    🔐

    DB 보안

    ⚠ 암호화 전 반드시 확인하세요

    • 비밀번호를 잊으면 암호화 DB를 복구할 수 없습니다. 비밀번호 재설정이나 우회 복구 기능은 없습니다.
    • 작업 전 DB를 백업하고, 완료 후 암호화된 DB 백업을 새로 만드세요. 백업도 다른 저장장치에 보관하세요.
    • DB 암호화만으로 미디어 파일은 보호되지 않습니다. 기존 평문 DB와 이전 백업도 그대로 남습니다.
    • 추가 저장 공간이 필요합니다. 작업 중 앱을 종료하거나 NAS·저장장치 연결을 끊지 마세요.

    ⌨ 키보드 단축키

    입력 중에는 F1·Ctrl+F만 사용할 수 있으며, 한글 조합 중에는 동작하지 않습니다. 영문 키는 한/영 전환과 관계없이 같은 키 위치를 사용합니다. 현재 화면에 해당하는 단축키만 동작합니다.

    압축 파일에서 이미지 삭제

    삭제할 이미지를 여러 개 선택하세요. 최소 한 장은 남겨야 합니다.

    선택한 이미지를 암호화 압축 파일에서 삭제합니다. 완료 후 앱에서 되돌릴 수 없으며, 복원할 압축 파일에서도 제외됩니다. 해당 페이지의 북마크와 대표 썸네일도 함께 정리합니다.

    새 암호화 사본을 검증한 뒤 교체하므로 추가 저장 공간과 시간이 필요합니다. 남아 있는 평문 원본은 이미지 삭제 전에 암호화 관리에서 먼저 정리해 주세요. 기존 백업은 그대로 남습니다. 완료 후 DB와 암호화 미디어 백업을 함께 갱신해 주세요.

    암호화 압축 파일 이름 변경

    복원 파일명까지 바꾸면 암호화 사본을 새로 만들고 검증합니다. 파일 크기만큼 추가 공간과 시간이 필요하며, 평문 임시 파일은 만들지 않습니다. 남아 있는 평문 원본의 이름은 유지합니다.

    완료 후 DB와 암호화 미디어 백업을 갱신해 주세요. 체크를 끄면 목록에 표시되는 이름만 바꿉니다.

    🔒 미디어 암호화

    영상 · ZIP · tar.zst 암호화 및 평문 원본 관리

    ⚠ 암호화 전 반드시 확인하세요

    • vault.key와 비밀번호가 모두 필요합니다. 둘 중 하나라도 잃으면 암호화된 미디어를 복원할 수 없습니다.
    • 암호화 파일이 손상되면 키와 비밀번호가 있어도 복원하지 못할 수 있습니다.
    • 완료 후 DB 백업(.vtbackup: DB와 vault.key)과 암호화 미디어를 각각 다른 저장장치에 백업하세요. DB 백업에는 미디어 본문이 포함되지 않습니다.
    • 평문 원본은 자동 삭제되지 않습니다. 암호화 파일의 열람·복원과 백업을 확인한 뒤 원본을 정리하세요.
    • 추가 저장 공간이 필요합니다. 작업 중 앱을 종료하거나 NAS·저장장치 연결을 끊지 마세요.
